# PDF Tools complete static project

No backend, no build step. Includes 17 tool pages, shared CSS/JS, pdf-lib 1.17.1, PDF.js 4.10.38, JSZip, FileSaver, html2canvas and jsPDF.

Important: Protect PDF does not fake encryption. Compress and Unlock rebuild pages as raster images. PDF-to-Word-ish exports a Word-compatible .doc HTML file and does not OCR scans. Sign uses a typed signature baseline.

Deploy the folder to GitHub Pages, Netlify or Vercel and point pdf.bishnulamsal.com.np to the host. For maximum CDN independence, self-host the pinned libraries after testing.
